# projectmodel + temporalgen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract `framework-go-projectmodel` (shared, validating project.json loader) into archistrator-platform, build `framework-go-app-generator/temporalgen` (per-manager Temporal activities/invokers/worker emitters), and migrate archistrator's 5 managers onto the generated code.

**Architecture:** projectmodel parses + cross-validates the codegen-relevant subset of project.json (serviceContracts incl. `deps`, systemDesign components/relationships) with tolerant reads; temporalgen consumes the model and emits, per manager, `activities.gen.go` (one activity per op of each **component** RA dep), `invokers.gen.go` (typed workflow-side callers — the enforcement surface), `worker.gen.go` (TaskQueue + RegisterWorker driven by a hand-written per-manager manifest for workflows + hybrid custom activities). Managers migrate one at a time; hybrid activities (capability type-assertions, envelope codecs, behavior-carrying adapters) stay hand-written in `activities_custom.go` and shrink via earmarked contract promotions.

**Tech Stack:** Go 1.25, `encoding/json` only in projectmodel (dependency-free), `go/format` + golden-file tests in emitters (httpgen pattern), Temporal Go SDK (emitted code only).

**Spec:** `docs/superpowers/specs/2026-07-06-app-generator-codegen-design.md` (delivery steps 1 of 6).

## Global Constraints

- Platform module paths: `github.com/mixofreality-studio/archistrator-platform/framework-go-projectmodel` and `.../framework-go-app-generator`; `go 1.25.0` in go.mod (matches http-generator).
- `framework-go-projectmodel` is **dependency-free** (`encoding/json` only) — same posture as the embedded `contract/` packages it replaces.
- `framework-go-app-generator` requires projectmodel with `replace ... => ../framework-go-projectmodel` for standalone builds (http-generator's framework-go pattern).
- All emitters: deterministic + byte-idempotent (sorted map iteration, `go/format.Source` before write), emit text, never compile the target.
- Both new modules must pass `archistrator-platform/.golangci.yml` v2 gates: funlen 60/40, gocyclo/gocognit 10, nestif 4, interfacebloat 12, gosec, gochecksumtype. Generated-file header `// Code generated by temporalgen. DO NOT EDIT.` (auto-excluded from lint).
- All archistrator gen/build/test commands run `GOWORK=off` from `archistrator/server` (Makefile convention).
- Add both new module dirs to `archistrator/go.work` `use` list (local dev override); platform `go.work` does NOT list generators — keep that convention.
- **Idempotency key standard:** the 3-part run-scoped `workflowID:runID:activityID` (systemdesign's corrected form). construction/operations/billing migrate from 2-part — a deliberate behavior change.
- **Deploy precondition (whole migration):** activity payload arity/shape changes make old-name aliases useless (recorded single-struct args cannot decode into multi-param generated activities), so there is **no alias table** — deviation from spec, reason: aliasing cannot preserve replay across arity changes. Instead: drain in-flight workflows (no active design sessions / construction pumps / billing cycles) before deploying each migrated manager. Archistrator is pre-launch single-operator; record the precondition in each migration commit message.
- **Deviation from spec:** engine direct-call wrappers are NOT emitted in step 1 (all 5 engines are pure — zero `deps` — and already called directly; a wrapper would have to invent a `fweng.Context`-in-workflow bridging convention mid-migration). Earmarked with op-level allowlists.
- Commit style: existing repo convention, e.g. `temporalgen: <what>` / `projectmodel: <what>`; platform commits in archistrator-platform repo, migration commits in archistrator repo.

## Shared migration recipe (used by Tasks 9–13)

Each manager migration follows the same moves; the per-task tables say which activity lands where:

1. Run `make gen-temporal` → `activities.gen.go`, `invokers.gen.go`, `worker.gen.go` appear in the manager package.
2. Rename `activities.go` → `activities_custom.go`; delete every activity the table marks **generated** (its body is now dead); keep every **custom** one.
3. Write the hand manifest `workermanifest.go` (workflow funcs + custom activities + options hook reproducing the package's current presets).
4. Rewrite workflow call sites: `workflow.ExecuteActivity(optsCtx, wf.XActivity, args)` → `wf.Acts.<Dep>.<Op>(ctx, args...)` for generated ops (the invoker applies options via the hook). Custom activities keep their current call form.
5. Delete `worker.go` (generated `RegisterWorker` + manifest replace it).
6. `GOWORK=off go build ./... && GOWORK=off go test ./internal/manager/<pkg>/...` then the systemtests slice.
7. Byte-idempotency: re-run `make gen-temporal`, `git diff --exit-code`.
8. Commit.

**Classification rules** (how each existing activity was sorted, applies if implementer finds drift):
- Wraps exactly one op of a **component dep's contract**, any arg reshaping is pure and movable into the workflow → **generated**.
- Type-asserts a capability extension (`BranchAware…`/`Ledger…`/`Provenance…`/`Reconciling…`), decodes/encodes a manager-local envelope, synthesizes errors, or wraps a plain-`goType` dep (no contract) → **custom**.
- Money-move ops needing business-stable keys (billing gateway) → **generated with caller-supplied key** (`CallerKeyedOps` config).

```go
// contract.go
package projectmodel

import (
	"encoding/json"
	"fmt"
)

// Contract is one parsed .serviceContracts entry: the self-describing metadata
// plus the embedded contract document (title/$defs/interface). Unknown fields
// are ignored and absent fields default — every old document parses under
// every newer projectmodel (spec: Schema ownership & evolution).
type Contract struct {
	Key       string // the serviceContracts map key (camelCase component key)
	Component string // self-describing component field (== Key today)
	Layer     string // "Manager" | "Engine" | "ResourceAccess" | "Client" | "Utility"
	GoPackage string // e.g. "internal/manager/billing"; empty ⇒ no Go emission target
	Infra     []string
	Stub      bool
	Deps      []Dep
	Doc       *Doc
}

// Dep is one DI constructor dependency. Exactly one of Component / GoType is
// set: a COMPONENT dep references another serviceContracts entry; a PLAIN dep
// carries a verbatim Go type (+ optional import).
type Dep struct {
	Name      string `json:"name"`
	Component string `json:"component,omitempty"`
	GoType    string `json:"goType,omitempty"`
	GoImport  string `json:"goImport,omitempty"`
}

// ParseContract parses one serviceContracts entry. The raw entry doubles as
// the contract document Parse consumes (title/$defs/interface).
func ParseContract(key string, raw json.RawMessage) (*Contract, error) {
	var meta struct {
		Component string   `json:"component"`
		Layer     string   `json:"layer"`
		GoPackage string   `json:"goPackage"`
		Infra     []string `json:"infra"`
		Stub      bool     `json:"stub"`
		Deps      []Dep    `json:"deps"`
	}
	if err := json.Unmarshal(raw, &meta); err != nil {
		return nil, fmt.Errorf("contract %s: metadata: %w", key, err)
	}
	doc, err := Parse(raw)
	if err != nil {
		return nil, fmt.Errorf("contract %s: %w", key, err)
	}
	return &Contract{
		Key: key, Component: meta.Component, Layer: meta.Layer,
		GoPackage: meta.GoPackage, Infra: meta.Infra, Stub: meta.Stub,
		Deps: meta.Deps, Doc: doc,
	}, nil
}
```

```go
// system.go
package projectmodel

import (
	"encoding/json"
	"strings"
)

// System is the codegen-relevant slice of the systemDesign slot model
// (slots[kind=5].model): the component inventory + the relationship edges.
// dynamicViews and all other fields are deliberately not parsed (tolerant
// subset — spec: Schema ownership & evolution).
type System struct {
	Components    []SystemComponent `json:"components"`
	Relationships []Relationship    `json:"relationships"`
}

type SystemComponent struct {
	ID    string `json:"id"`   // kebab-case ("system-design-manager")
	Name  string `json:"name"` // PascalCase ("SystemDesignManager")
	Kind  string `json:"kind"`
	Layer string `json:"layer"`
}

type Relationship struct {
	From  string `json:"from"` // kebab component id
	To    string `json:"to"`
	Mode  string `json:"mode"` // "sync" | "queued"
	Label string `json:"label"`
}

func ParseSystem(slotModel json.RawMessage) (*System, error) {
	var s System
	if err := json.Unmarshal(slotModel, &s); err != nil {
		return nil, err
	}
	return &s, nil
}

// ComponentByContractKey joins a camelCase serviceContracts key to its
// systemDesign component — the Go port of the webApp's
// resolveContractComponentId: (1) Kebab(key) match on ID, (2) case-insensitive
// ID match, (3) case-insensitive Kebab(name) match. Honest miss on no match.
func (s *System) ComponentByContractKey(key string) (*SystemComponent, bool) {
	kebab := Kebab(key)
	for i := range s.Components {
		if s.Components[i].ID == kebab {
			return &s.Components[i], true
		}
	}
	for i := range s.Components {
		if strings.EqualFold(s.Components[i].ID, key) {
			return &s.Components[i], true
		}
	}
	for i := range s.Components {
		if strings.EqualFold(Kebab(s.Components[i].Name), kebab) {
			return &s.Components[i], true
		}
	}
	return nil, false
}
```

```go
// projectmodel.go
package projectmodel

import (
	"encoding/json"
	"fmt"
	"os"
	"sort"
)

// Model is the validated codegen view of one project.json.
type Model struct {
	Contracts map[string]*Contract
	System    *System
	Warnings  []string
}

func LoadFile(path string) (*Model, error) {
	raw, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	return Load(raw)
}

// Load parses the codegen-relevant subset and cross-validates it. Unknown
// fields anywhere are ignored; the systemDesign slot is located by kind==5.
func Load(raw []byte) (*Model, error) {
	var top struct {
		ServiceContracts map[string]json.RawMessage `json:"serviceContracts"`
		Slots            map[string]struct {
			Kind  int             `json:"kind"`
			Model json.RawMessage `json:"model"`
		} `json:"slots"`
	}
	if err := json.Unmarshal(raw, &top); err != nil {
		return nil, fmt.Errorf("projectmodel: %w", err)
	}
	m := &Model{Contracts: map[string]*Contract{}}
	keys := make([]string, 0, len(top.ServiceContracts))
	for k := range top.ServiceContracts {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	for _, k := range keys {
		c, err := ParseContract(k, top.ServiceContracts[k])
		if err != nil {
			return nil, err
		}
		m.Contracts[k] = c
	}
	for _, slot := range top.Slots {
		if slot.Kind == 5 && len(slot.Model) > 0 {
			s, err := ParseSystem(slot.Model)
			if err != nil {
				return nil, fmt.Errorf("projectmodel: systemDesign slot: %w", err)
			}
			m.System = s
		}
	}
	if err := m.validate(); err != nil {
		return nil, err
	}
	return m, nil
}
```

```go
// validate.go
package projectmodel

import "fmt"

// legalDepTargets is the Method's downward-only call legality for COMPONENT
// deps ([[the-method-layers]]): who may depend on whom. Utility targets are
// exempt (anyone calls Utilities); plain goType deps are exempt (no contract).
var legalDepTargets = map[string]map[string]bool{
	"Client":         {"Manager": true},
	"Manager":        {"Engine": true, "ResourceAccess": true},
	"Engine":         {"ResourceAccess": true},
	"ResourceAccess": {},
}

func (m *Model) validate() error {
	for _, c := range sortedContracts(m.Contracts) {
		for _, d := range c.Deps {
			if d.Component == "" {
				continue // plain dep
			}
			target, ok := m.Contracts[d.Component]
			if !ok {
				return fmt.Errorf("projectmodel: contract %s dep %q: unknown component %q", c.Key, d.Name, d.Component)
			}
			if target.Layer == "Utility" {
				continue
			}
			if allowed, known := legalDepTargets[c.Layer]; known && !allowed[target.Layer] {
				return fmt.Errorf("projectmodel: contract %s (%s) dep %q → %s (%s): layer rule violation", c.Key, c.Layer, d.Name, d.Component, target.Layer)
			}
		}
	}
	if m.System != nil {
		ids := map[string]bool{}
		for _, sc := range m.System.Components {
			ids[sc.ID] = true
		}
		for _, r := range m.System.Relationships {
			if !ids[r.From] || !ids[r.To] {
				return fmt.Errorf("projectmodel: relationship %s→%s: unresolved endpoint", r.From, r.To)
			}
		}
		for _, c := range sortedContracts(m.Contracts) {
			if c.GoPackage == "" || c.Stub {
				continue
			}
			switch c.Layer {
			case "Manager", "Engine", "ResourceAccess":
				if _, ok := m.System.ComponentByContractKey(c.Key); !ok {
					m.Warnings = append(m.Warnings, fmt.Sprintf("contract %s: no systemDesign component joins", c.Key))
				}
			}
		}
	}
	return nil
}

func sortedContracts(cs map[string]*Contract) []*Contract { /* sort by Key, return slice */
	out := make([]*Contract, 0, len(cs))
	for _, c := range cs {
		out = append(out, c)
	}
	sortContractsByKey(out)
	return out
}
```

```go
	"go.temporal.io/sdk/workflow"

// genInvokers is the workflow-side typed call surface: one method per
// generated activity. Workflows hold one; no string activity names and no
// interface{} results appear in hand-written workflow code. Opts, when
// non-nil, overrides the per-op ActivityOptions (the manager's hand-written
// preset hook); the generated default applies otherwise.
type genInvokers struct {
	Opts func(activityName string) (workflow.ActivityOptions, bool)
}

// genDefaultActivityOptions is the uniform generated preset: 15s
// StartToClose, terminal on ContractMisuse (the workflow-level Conflict
// re-read loop and category presets live in the manager's Opts hook).
func genDefaultActivityOptions() workflow.ActivityOptions {
	return workflow.ActivityOptions{
		StartToCloseTimeout: 15 * time.Second,
		RetryPolicy: &temporal.RetryPolicy{
			NonRetryableErrorTypes: []string{fwmanager.RAErrType(fwra.ContractMisuse)},
		},
	}
}

func (i genInvokers) options(ctx workflow.Context, name string) workflow.Context {
	opts := genDefaultActivityOptions()
	if i.Opts != nil {
		if o, ok := i.Opts(name); ok {
			opts = o
		}
	}
	return workflow.WithActivityOptions(ctx, opts)
}

// BillingStateReadBilling invokes activity "billingStateAccess.readBilling".
func (i genInvokers) BillingStateReadBilling(ctx workflow.Context, customerID billingstate.CustomerID) (billingstate.BillingAccount, error) {
	var out billingstate.BillingAccount
	err := workflow.ExecuteActivity(i.options(ctx, "billingStateAccess.readBilling"), "billingStateAccess.readBilling", customerID).Get(ctx, &out)
	return out, err
}
```

```go
	"go.temporal.io/sdk/workflow"

// RegisterWorker: the workflow functions (codegen cannot know them), any
// hybrid hand-written activities, the invoker options hook, and the

	}
}
```

```go
// invokers/worker) from project.json via framework-go-projectmodel +

// `make gen-temporal`.

	"fmt"
	"os"
	"path/filepath"

	"github.com/mixofreality-studio/archistrator-platform/framework-go-app-generator/temporalgen"
	projectmodel "github.com/mixofreality-studio/archistrator-platform/framework-go-projectmodel"
)

	projectFile  = "../.aiarch/state/project.json"
	serverModule = "github.com/mixofreality-studio/archistrator/server"
)

// callerKeyedOps: ops whose idempotency is BUSINESS-stable, not run-scoped —
// the workflow supplies the key explicitly (billing money-moves; see
// gatewayIdempotencyKey in internal/manager/billing).

}

var managers = []string{"systemDesignManager", "projectDesignManager", "constructionManager", "operationsManager", "billingManager"}

func main() {
	path := projectFile
	if len(os.Args) > 1 {
		path = os.Args[1]
	}
	m, err := projectmodel.LoadFile(path)
	if err != nil {
		fatal(err)
	}
	for _, w := range m.Warnings {
		fmt.Fprintln(os.Stderr, "appgen warning:", w)
	}
	for _, key := range managers {
		files, err := temporalgen.Generate(m, temporalgen.Config{
			ModulePath: serverModule, ManagerKey: key, CallerKeyedOps: callerKeyedOps[key],
		})
		if err != nil {
			fatal(fmt.Errorf("%s: %w", key, err))
		}
		dir := m.Contracts[key].GoPackage
		for name, content := range files {
			if err := os.WriteFile(filepath.Join(dir, name), content, 0o644); err != nil {
				fatal(err)
			}
		}
		fmt.Printf("appgen: %s → %s (%d files)\n", key, dir, len(files))
	}
}

func fatal(err error) { fmt.Fprintln(os.Stderr, "appgen:", err); os.Exit(1) }
```
