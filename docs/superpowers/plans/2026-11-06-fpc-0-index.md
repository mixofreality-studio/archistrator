## Global Constraints (apply to every task in every plan)

**GC-1 Declarative-only agent inputs.** An agent never writes code that runs inside a test, a gate, or a generator. The only agent-authored artifacts in the test pipeline are typed records in `project.json` (`testPlan`, `acceptancePlan`, `uiDesign`, `deliverySurfaces`). Every record is complete by schema: `required` on every field that carries an assertion, and non-emptiness enforced in Go at the record verb (`required` is presence-only; see memory "contract strictness"). A record that could describe a vacuous test is unrepresentable, not merely refused.

**GC-2 Sum types for every choice; exhaustive handling everywhere.**
- Go: a closed choice is a sealed interface with an unexported marker method and a `//sumtype:decl` comment; every variant is a struct; every `switch v := x.(type)` over it has no `default` and is checked by `gochecksumtype` (already in the lint set). JSON wire form is `{"kind": "<variant>", ...}` via a generated `UnmarshalJSON` that refuses unknown kinds. modelgen emits these from JSON Schema `oneOf` + `discriminator.propertyName = "kind"` (Plan 1 Task 1.1 adds that capability if absent).
- TypeScript: discriminated unions on `kind`, consumed only through a `switch` whose `default` is `assertNever(x)`.
- Applies to: `TestArg` values (literal | ref), `ArrangeCall` (contractCall | advanceClock | failNext | seedResource), `UIAction` (one variant per action kind), `UIObservable` (one per observable kind), `Target` (role-scoped), `Outcome` attachment (componentOutcome | actorOutcome), `FailureCause`, generator `Output.role`, `TaskKind` (dispatch | review | job), `Surface`.

**GC-3 No prose where a rule reads.** Any field a methodcheck rule, generator or gate reads is typed. Narrative stays in `Content`/`notes` fields that nothing reads.

**GC-4 Every new rule ships with a violating fixture** and a passing fixture in the same commit (methodcheck convention), and is registered in the doctrine registry (Plan 6) with `enforcedBy` set.

**GC-5 Every schema change conforms archistrator's own `project.json` in the same change** (B11) — but under ruling 8 the new *rules* are Warning for the own project via a dated waiver; the *schema* still has to load.

**GC-6 Platform changes are released and pinned** per plan: tag, push, bump `server/go.mod` pins, `GOWORK=off go test -p 1 ./...` green in the app before the plan is done. Platform repo-local git identity is "uitests": commit as David Marne.

**GC-7 Tests only on changed packages during a task; full suite once at the end of each plan.** (Founder, 2026-11-02.)

**GC-8 Never reset/rebase/stash on shared trees; explicit-path staging only; ListAgents + `git fetch` before any push to main.**
