# appgen Step 5: transportgen — generated Go client SDK (HTTP + MCP)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps.

**Goal:** A platform emitter producing a SELF-CONTAINED typed Go client SDK per manager contract (HTTP + MCP), replacing systemtests' hand transports (~1,700 L: httptransport 612 + mcptransport 595 + transport 192 + enum tables) and becoming a delivered-app artifact.

**Recon (2026-07-09, plan-grade — trust it):** httpgen's `planOps` (plan.go:37-160) is the single route/verb/path-param/body truth the client must mirror; success = bare result JSON, void = 204, errors = `{"error","code"}` with the fwm kind→status map; mcp tool = `lowerFirst(managerBase)+Op`, input struct of all params, output `{"result":T}`, errors as `isError` text `"<Kind>: <Detail>"`, streamable HTTP at /mcp with Mcp-Session-Id. systemtests: module is STDLIB-ONLY (depguard + constitution test), cannot import server/internal or platform modules → SDK must be emitted zero-import source in-module (gen-systemtests precedent: server-side cmd writes ../systemtests/internal/generated with prune/hash/drift discipline). DTO casing is $def-driven (operations PascalCase, others camelCase) — emit from $defs, never by convention. Enum wire = bare ints; emitting modelgen-style enum consts + varname bridges kills every hand ordinal table. uuid params → emit as `string` (wire-identical; preserves zero-dep). Client-policy quirks stay in harness, not SDK: SubmitSDPDecision's `"-"` optionID placeholder; POST ops always send the body wrapper (even `{}`) — that part IS generic emitter behavior (handler always decodes a body).

### Task P3 (platform): the transportgen emitter
New framework-go-app-generator/transportgen: `Generate(m *projectmodel.Model, cfg Config{Managers []string, PackageName string, UUIDAsString bool}) (map[string][]byte, error)` emitting a single self-contained package:
- types.gen.go per manager (via P2 entry): result/param DTOs, enums with varname string bridges (`ArtifactKindName(k)` style), sums.
- http.gen.go: `HTTPClient{BaseURL, HTTP *http.Client, Bearer string}` + one typed method per op driven by P1's OpPlan — path assembly (ID scalars stringified into segments), query encoding for GETs, POST body wrapper structs (always sent, `{}` when empty), bare-result/204 decode, error envelope decode into `*APIError{Status int, Code, Detail string}`.
- mcp.gen.go: `MCPClient` + per-op methods via a small emitted streamable-HTTP JSON-RPC/SSE core (initialize/initialized/session header/tool call, modeled on the hand mcptransport loop), input structs of all params, `{"result":T}` decode, `isError` text parsed into `*MCPToolError{Kind, Detail string}`.
- Golden tests: greenfield fixture trio; ARCHISTRATOR FIDELITY test: emit for the 5 managers and assert the generated route table (verb+path per op) EQUALS a hand-pinned expectation table transcribed from the recon/httptransport for all 23 Transport-covered ops (this is the byte-exact mirror proof); compile-proof sample (stdlib-only — assert the emitted package builds with `GOFLAGS=-mod=mod` in an empty-module sandbox and imports NOTHING beyond stdlib).
Commit(s).
